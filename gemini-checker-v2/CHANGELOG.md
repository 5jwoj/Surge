## 版本规范

### 版本号格式: X.Y.Z

- **X (主版本号)**: 不兼容的 API 修改
- **Y (次版本号)**: 向下兼容的功能性新增
- **Z (修订号)**: 向下兼容的问题修正

### 更新类型标识

- `新增` - 新功能
- `修改` - 已有功能的变更
- `弃用` - 即将移除的功能
- `移除` - 已移除的功能
- `修复` - Bug 修复
- `安全` - 安全漏洞修复

# iOS Shortcuts 快捷指令配置

本目录包含可导入 iOS 快捷指令的配置。

## 快捷指令列表

### 1. 检测 Gemini（当前节点）
**功能**: 快速检测当前代理节点是否可访问 Gemini

**创建步骤**:
1. 打开 iOS "快捷指令" 应用
2. 点击右上角 "+" 创建新快捷指令
3. 添加以下操作:
   - **URL**: `http://gemini-check.local/current`
   - **获取 URL 内容** (Get Contents of URL)
4. 命名为 "检测 Gemini"
5. 添加到主屏幕或 Widget

**触发方式**:
- 手动点击快捷指令
- 通过 Siri: "嘿 Siri，检测 Gemini"
- Widget 快速访问

---

### 2. Gemini 批量检测
**功能**: 批量检测所有节点，找出可用节点

**创建步骤**:
1. 打开 iOS "快捷指令" 应用
2. 点击右上角 "+" 创建新快捷指令
3. 添加以下操作:
   - **URL**: `http://gemini-check.local/all`
   - **获取 URL 内容**
   - **显示通知**: 内容为"批量检测已启动，请稍候..."
4. 命名为 "Gemini 批量检测"

**注意**: 批量检测需要 1-3 分钟，请耐心等待

---

### 3. 自动检测（打开应用时）
**功能**: 打开 ChatGPT/Gemini 应用时自动检测节点

**创建步骤**:
1. 打开 "快捷指令" 应用
2. 切换到 "自动化" 标签
3. 点击 "+" 创建个人自动化
4. 选择 "App" 触发器
5. 选择应用: Safari / Chrome / 任何可能访问 Gemini 的应用
6. 选择 "打开时"
7. 添加操作: "运行快捷指令" → 选择 "检测 Gemini"
8. **关闭** "运行前询问"（重要）
9. 完成

**效果**: 每次打开相关应用时，自动在后台检测节点，如不可用会弹出通知提醒

---

### 4. 定时自动检测
**功能**: 每天固定时间自动检测

**创建步骤**:
1. 打开 "快捷指令" 应用
2. 切换到 "自动化" 标签
3. 点击 "+" 创建个人自动化
4. 选择 "特定时间"
5. 设置时间（如每天早上 9:00）
6. 添加操作: "运行快捷指令" → 选择 "检测 Gemini"
7. **关闭** "运行前询问"
8. 完成

## 高级用法

### 组合快捷指令：智能切换

创建一个更智能的快捷指令：

**步骤**:
1. 创建新快捷指令
2. 添加操作:
   ```
   URL: http://gemini-check.local/current
   获取 URL 内容
   
   如果 [URL内容] 包含 "不可访问"
       显示通知: "当前节点不可用，正在批量检测..."
       URL: http://gemini-check.local/all
       获取 URL 内容
   否则
       显示通知: "✅ 当前节点可用，延迟良好"
   结束
   ```

### Widget 快速访问

1. 长按主屏幕空白处进入编辑模式
2. 点击左上角 "+" 添加 Widget
3. 选择 "快捷指令"
4. 选择合适的尺寸
5. 点击 Widget 配置
6. 选择 "检测 Gemini" 快捷指令
7. 完成

现在可以直接在主屏幕点击 Widget 快速检测！

## 故障排除

### 快捷指令没有反应
- 检查 Surge/Quan X 是否在运行
- 检查重写规则是否启用
- 尝试手动运行脚本测试

### 提示 "无法连接"
- 确认已正确配置重写规则
- URL 必须完全匹配 `http://gemini-check.local/current` 或 `/all`
- 检查网络状态

### 自动化不执行
- 确保 "运行前询问" 已关闭
- 检查 iOS 系统设置 → 快捷指令 → 高级 → 允许运行自动化

## 分享快捷指令

创建好的快捷指令可以分享给其他人：

1. 打开快捷指令
2. 点击右上角 "…" 菜单
3. 点击 "分享"
4. 选择 "iCloud 链接"（需要 iCloud 账号）
5. 复制链接发送给朋友

**提示**: 接收者需要先安装 Surge/Quan X 并配置好重写规则

## 示例场景

### 场景 1: 早晨例行检查
- 自动化: 每天早上 8:00 自动检测
- 如果发现不可用，立即收到通知
- 手动运行批量检测，切换到最佳节点

### 场景 2: 使用 Gemini 前
- 主屏幕 Widget 一键检测
- 确认可用后再打开 Gemini
- 避免浪费时间在无法访问的节点上

### 场景 3: 切换网络环境
- 从 WiFi 切换到 4G/5G 时触发检测
- 确保新环境下节点仍可用
- 自动调整到最佳状态
